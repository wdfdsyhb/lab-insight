# 【StudyHack】LabInsight 实验数据分析助手——串口日志粘进去，实验报告拿出来

## 一、自我介绍

我是陈兴洪，上海商学院物联网工程专业大二学生，方向嵌入式。平时做课设就是跟传感器、串口、单片机打交道，实验数据动辄几百行，每次整理数据的时间比分析数据的时间还长。

## 二、我的作品是什么

一句话说清谁在什么场景下用：**嵌入式方向的学生在整理实验数据、写实验报告时**，用 LabInsight 把乱糟糟的串口日志或 CSV/Excel 原样丢进去，自动完成清洗、校准换算、可视化、滤波分析，最后生成一份能直接交的实验报告。

它是一条完整的流水线，**七个页签**对应实验数据处理的完整流程：

1. **导入数据**：CSV/Excel 拖进去，串口日志直接粘——带 `[INFO]` 前缀、乱码行、CRC 失败帧都能自动清洗掉，脏行跳过并计数，不会整体报错；还支持**实时串口采集**（浏览器直连开发板，边采边画实时曲线，采集时按空格打标记，没有硬件也能用模拟数据流走完整流程）、**多份同结构数据按行合并**（按列名对齐拼接）；项目自动保存在浏览器本地，刷新可恢复
2. **数据预览**：清洗后的表格 + 采样质量体检（实际采样率、平均/标称间隔、间隔抖动、丢帧检测、时间戳一致性检查）+ **数据体检卡**（缺失值/重复行/常数列检查，一键清理可撤销）；清洗后的数据可一键导出 CSV / Excel
3. **校准换算**：原始电信号变物理量——NTC 热敏电阻（B 值式 / Steinhart-Hart）、ADC 读数转电压、MQ 系列电阻比转浓度，公式和参数全部写在页面上可追溯；**线性拟合**（输出 R² 与评语）、**标定评估**（灵敏度/零点/线性度/迟滞）与 **NTC 理论 R-T 曲线对比**、**自定义多项式换算**（y = ax+b / y = ax²+bx+c）、**两点标定**（两组标准温度-实测电阻反算 B 与 R₀，可从标定图首尾两点取值）、**NTC 型号预设**（B 值与 R₀ 一键填充）；批量模式能把已导入数据的某一列整体换算成新列，原始数据不动
4. **智能分析**：统计卡片（含**标准误与 95% 置信区间**，t 分布口径标注）；多 Y 轴趋势图表（折线/散点可切、滚轮缩放、回放动画、**300dpi PNG 与 SVG 矢量导出**、**框选区间实时统计**）；**异常判定口径可切换**（3σ / IQR / 稳健 z-MAD，图上同步画阈值虚线）；**每通道直方图**；**通道相关系数矩阵**（Pearson r）；**测量不确定度计算**（A 类/B 类/合成/扩展）；**多组并列对比**（多组数据叠图 + 均值 ± 标准差带，粘贴或从 CSV/Excel 文件加组）；**图表误差棒**（每点 ±U 按通道）；**实验事件标注**（图上打点、列表管理、进报告）；自动生成中文分析结论——趋势、波动、异常毛刺定位到具体时间戳、分段描述、行动建议
5. **工具箱**（嵌入式落地辅助）：**生成 C 代码**（NTC B 值式+分度表 / Steinhart-Hart / ADC 转电压 / 多项式，读校准参数一键复制，另可导出头文件 .h）；**采样率/定时器助手**（STM32 PSC/ARR、Arduino OCR1A、过采样提示）；**分压电阻与 ADC 位数助手**（E24 阻值推荐）；**十六进制字节流解码**（ASCII / uint16 / int16）；**Arduino 完整示例**（按所选换算生成 .ino，一键下载即可烧录）
6. **滤波实验**：滑动平均 / 中值滤波 / 一阶低通三种滤波器勾选叠加对比，统计卡片直接显示处理前后「标准差 / 极差 / 异常点数」的变化；还带 FFT 频域分析——本地自实现 Cooley-Tukey 算法、自动标注主频/次频、直流分量单独注明、奈奎斯特频率上限提示（非均匀采样自动重采样后变换）
7. **生成报告**：一键套模板生成实验报告，**器材/实验步骤/注意事项/数据记录说明都是选填区块**，空了自动省略、编号自动收敛；一键复制、导出 .txt/.md、**Word（.docx，真表格与嵌入图表）**、**单文件 HTML**、打印另存 PDF（打印版自动附图表附录）；统计表可复制 **LaTeX**；**仪器台账**（名称/型号/编号/精度允差/校准日期）可直接填进报告器材节；**实验事件记录**随图标注进报告；**误差分析与讨论**自动成节（采样质量、异常检测、不确定度汇总，给出可信度结论与主要误差来源）；**全程操作流水自动写入报告**，每步可复现

**30 秒快速体验**：打开链接 → 点「CSV 示例」→「开始解析」→「智能分析」看统计卡片和三 Y 轴曲线 →「滤波实验」勾"中值滤波"看前后对比 →「生成报告」看自动生成的报告。全程不用注册、不用装任何东西。

## 三、为什么做

我们专业做课设的真实流程是这样的：串口助手采一小时数据 → 手动复制到 Excel → 手动删日志前缀和乱码行 → 想看真实温度还得查手册把电阻值换算回去 → 手动算均值方差 → 手动画图 → 手写"本实验表明……"。每次都要花一两个小时在"整理"而不是"分析"上。

市面上的工具各管一段：Excel 能算但读不懂串口日志；串口助手能采不能分析；Python 脚本什么都行但要现学。我想做的就是把这整条流水线搬进浏览器：**丢进去 → 点几下 → 报告出来**。

有两个设计决定是我自己坚持的：

- **纯前端，数据不出浏览器**。所有数据在本地处理，不上传任何服务器——这一点对实验室数据来说是底线。
- **核心功能零依赖可用，且完全离线**。不填 API Key、不联网也能走完全部流程。分析结论由本地规则引擎生成（趋势判断、波动分级、离群检测、分段描述），不依赖任何大模型接口；所有前端依赖（Chart.js / PapaParse / SheetJS / zoom / docx）都已内置到本地 vendor 目录，断网或校园网屏蔽 CDN 也能用，双击 index.html 即开。页面底部留了一个可选的"深度分析"框，想用大模型的同学可以自己贴 Key，但它不是必需品。

## 五、用 Qoder 做出来的过程

整个项目的开发与部署均由 Qoder 完成，我负责提需求、定验收标准、实测把关，前后 30 多轮对话。

**第 1 步：把想法交给 Qoder。** 我用一段话描述需求——"我是学物联网的，平时录串口采集的数据……想要一个网页，浏览器打开就能用：能把 CSV、Excel 传进去，也能把串口那种有点乱、带些杂讯的日志直接粘进去；它自己把数据洗干净、整理成表格；自动算最大值、最小值、平均值、标准差；出折线图；还能自己给出一段分析结论；最后点一下能生成实验报告"——并附了一份我自己提前整理的需求说明（页面怎么拆、串口日志要能处理哪些脏情况、用什么图表库）。Qoder 读完直接开搭骨架。

<img src=https://static.tianchi.aliyun.com/userimg/1095281205549/2026-11-14/umuayi6nFGqU8e0W.png >

**第 2 步：核心模块逐个实现，我负责实测验收。** 解析引擎（脏行跳过、单位剥离、时间戳识别）、统计卡片、图表、中文结论引擎、报告模板，每完成一块我就用自己的测试数据过一遍。

**第 3 步：我发现问题，Qoder 修。** 最典型的一次：temp、humi、press 三个通道数值范围差很远（25 vs 62 vs 1013），三个曲线共用一个 Y 轴，温度和湿度被压成贴地的一条线，默认打开根本看不清趋势。我把问题反馈给 Qoder，它采用多 Y 轴方案修复：2~4 条通道时每条独立 Y 轴（左侧 1 条+右侧其余）、轴刻度用对应曲线的颜色标注、关到 1 条恢复单轴、5 条以上回退共享轴。修复后三条曲线都能清晰看到各自趋势。

**第 4 步：把"处理数据"升级成"完整工作流"。** v1 只做到统计和图表，我觉得专业纵深不够，又让 Qoder 加了传感器校准换算（NTC/ADC/MQ）、采样质量分析（丢帧检测）、滤波对比实验台、FFT 频域分析、PDF 导出、曲线回放。这些不是随便堆功能——NTC 换算用 Steinhart-Hart/B 值式是我们传感器课的内容，FFT 谱峰分析和工频干扰识别是信号课的内容，滤波器选型对比更是每个嵌入式课设都躲不掉的环节。通用工具不会管这些，但做实验的人天天需要。

**第 5 步：自动化验收。** 做完之后我没有只靠手点——写了一套浏览器自动化验收脚本，对线上版本跑了 40 多项断言：

- 13 个统计值全部与 Python 独立重算的结果交叉核对一致（样本标准差 n-1 口径）
- 构造含 3.5 秒断点的串口日志，丢帧检测准确报出 1 处；正常数据显示"疑似丢帧 0 处，采样连续"
- NTC 换算 R=5000Ω → 41.46°C（理论值 41.44°C）、ADC 2048 → 1.6504V（理论值 1.6504V）
- 滤波对比、FFT 谱峰标注、报告生成逐项验证
- 375px 手机窄屏无横向溢出、全程零控制台报错

**第 7 步：功能纵深迭代（v2.4~v2.9）。** 上线后我又提了一批嵌入式视角的进阶需求，Qoder 一轮轮做下来：异常判定口径可切换（3σ / IQR / 稳健 z-MAD，图上画阈值虚线）、采集面板实时增强（当前值/最值/时长、毛刺闪烁提醒）；完全离线化（五个依赖库全部搬进本地，断网可用）；报告编辑增强（器材/步骤/注意事项/数据记录说明选填区块，Word 导出支持真表格与嵌入图表）；实验事件标注（图上打点、随报告走）；多份数据合并与多组并列对比（叠图 + 均值 ± 标准差带）；图表 SVG 矢量与 300dpi 高清导出；仪器台账与**误差分析与讨论自动成节**（采样质量、异常检测、测量不确定度汇总，自动给出可信度结论与误差来源）；工具箱四件套（C 代码导出、采样率/定时器助手、分压电阻与 ADC 位数助手、十六进制解码）加 Arduino 完整 .ino 示例；校准页加两点标定反算 B 值与 NTC 型号预设；趋势图误差棒。每轮都是"提需求 → 实现 → 浏览器实测验收 → 记 CHANGELOG"闭环。

技术栈：纯前端 HTML/CSS/JS；所有前端依赖（Chart.js / PapaParse / SheetJS / chartjs-zoom / docx）**已内置本地 vendor 目录，完全离线可用**；FFT 为本地自实现的迭代式基-2 Cooley-Tukey 算法（页面注明实现说明，无外部依赖）；无后端、无数据库，数据全程在浏览器本地处理、不上传服务器。
