# 项目需求说明：实验数据处理小工具（LabInsight）

> 这是我自己提前整理的一些细节要求，给 Qoder 照着做。规则都可以实现，不清楚的先问我，别自己乱改架构。

## 这工具是干嘛的（一句话）

一个**浏览器里直接打开就能用**的网页：把我的实验数据（串口日志、CSV/Excel）丢进去，它自己完成清洗、整理、画图、分析、出报告，全程不用装环境、不用连服务器，数据也不传到网上。

## 必须遵守的几点（重要）

- **纯前端页面**：就是 HTML + CSS + JavaScript，不搞 Node、不搞 Python 后端、不用构建工具。
- **数据都在浏览器本地处理**，不发给服务器。
- **核心分析用本地规则算**（识别数值列、算统计量、判异常、找趋势、生成中文结论），**不依赖外部 API**。没有联网、没有 Key 也必须能用。
- 可以加一个"粘你自己的大模型 API Key 做深度分析"的折叠区当加分项，但**不是必需**，核心功能不靠它。
- 图形和表格那些库，全部用 CDN 在 HTML 里引（下面第 11 条列了），别下载到本地。
- 尽量收在 `index.html` 这一个入口，保证双击就能跑。
- 界面用**简体中文**。

## 页面风格（要好看，清爽）

参照 Notion / Linear 那种感觉：
- 背景近白（大概 `#fafafa` / `#fff`）。
- 卡片：白底、圆角（12~16px）、柔和的阴影、细边框。
- 文字：正文深灰（`#1f1f1f`~`#333`），次要的浅灰（`#666`）。
- 主色用**蓝青**（比如 `#2563eb` 或 `#0ea5e9`），鼠标悬停时深一点。
- 图表配色和主色统一。
- 布局：顶部一条固定导航 + 中间卡片区，留白多一点，不挤。
- 动画：卡片淡入、按钮悬停变个色/微缩——**克制**，别炫技。
- 响应式：电脑优先，但手机也能正常打开用。
- **不要**深色霓虹、重阴影堆、刺眼渐变。高级感靠留白和排版，不是堆装饰。

## 页面结构（顶部导航 + 四个页签）

顶部导航放 4 个页签，点一下切换内容（不跳页面）：
```
[ 名称，比如"实验数据分析助手 LabInsight" ]   导入数据 | 数据预览 | 智能分析 | 生成报告
```
数据还没导的时候，点哪个页签都提示"请先导入数据或加载示例数据"。

## 页签一：导入数据
- **拖拽上传 / 点选文件**，支持 `.csv` `.xlsx` `.txt`。
- **粘贴区**：串口那种日志直接粘进去（可能带乱码、前缀、奇怪换行）。
- **一键加载示例数据**（内置，别人没数据点一下也能体验全部功能）。
- **解析设置**（友好的说明）：
  - 数据从第几行开始（跳过头、日志前缀）
  - 有没有时间戳列、在哪一列
  - 分隔符（逗号 / Tab / 空格 / 自动识别）
- 点"开始解析"后给友好反馈，比如"识别到 3 列 · 共 240 行"、"有 2 行被跳过"。

## 页签二：数据预览
- 表格展示解析结果。
- **数值列**和文本列样式区分开，数值列高亮。
- 明显**异常点**标一下。
- 顶部小结：列数、行数、时间范围。
- 能看"原始文本"和"清洗后"对照（串口日志去了杂讯之后长啥样）。

## 页签三：智能分析（重点）
- **统计卡片**：对主要数值列算 最大 / 最小 / 均值 / 标准差 / 极差 / 漂移量，卡片网格摆出来。
- **图表**：折线图为主，能切散点图，能缩放看某段，多列能叠一起对比。用 Chart.js。
- **分析结论（最关键）**：本地规则引擎自动生成**一段通顺的中文结论**，比如：
  > "该时段温度整体呈上升趋势，均值 25.6°C，波动不大（标准差 0.8）；第 3 段有两处明显毛刺，疑似接触不良或偶发干扰，建议检查接线后复测。"
  规则要覆盖：趋势（涨/跌/平稳）、波动大小（按标准差区间）、异常检测（离群/阶跃）、分段描述。结论得**像人写的实验分析**，别干巴巴列数字。
- （加分项）"深度分析"折叠区：粘 API Key 后可让大模型做更开放的解读。

## 页签四：生成报告
- 一键生成**实验报告 / 课设说明书**文本。
- 套模板自动填：
  - 实验名称与目的（可编辑）
  - 设备与数据来源（用表里带出的信息）
  - 数据结果（统计 + 图表说明）
  - 分析结论（引第 3 页签生成的）
  - 附录（原始数据摘录）
- 提供"一键复制"和"导出 .txt/.md"。
- 报告排版清晰（有标题层级、分段）。

## 串口日志解析要"扛得住脏数据"
串口文本常见这些情况，解析器必须处理：
- 行首有前缀/乱码/日志级别（如 `[INFO]`）。
- 字段混用空格、Tab、逗号。
- 个别行错误/缺失 → 跳过并计数，别整体失败。
- 数值带单位（`25.3C`、`62.1%`）→ 剥离单位。
- 时间戳格式多（`HH:mm:ss.mmm` / 纯数字秒 / `yyyy-MM-dd HH:mm:ss`）→ 尽量自动识别。
- 中文编码：UTF-8 优先；GBK 实在处理不了就提示，别报错崩掉。

## 示例数据（内置，放 samples/ 目录）
- `sample_serial.txt`：真实感串口日志（时间戳 + 2~3 列数值，混点脏行/毛刺）。
- `sample_data.csv`：规整 CSV（时间戳 + 2~3 列数值）。
- 内置按钮点一下就能加载、走通"分析→图表→报告"全流程。

## 完成标准（交差前检查）
- 浏览器双击 `index.html` 能跑通全部功能。
- 三种输入（CSV / Excel / 粘串口日志）+ 示例数据都能走通。
- 表格、统计卡片、图表、结论、报告都可用、样式统一。
- 没有 API Key 也完整可用。
- 宽屏、手机窄屏都正常。

## 用的库（CDN 引入）
- Chart.js（图表）：`https://cdn.jsdelivr.net/npm/chart.js@4.4.1/dist/chart.umd.min.js`
- PapaParse（CSV 解析）：`https://cdn.jsdelivr.net/npm/papaparse@5.4.1/papaparse.min.js`
- SheetJS（读 Excel）：`https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js`
- 字体系统默认就行，想让中文更好看可引 Noto Sans SC（可选）。
