## 功能 A：传感器校准换算器（新页签「校准换算」）

放在「数据预览」和「智能分析」之间。做什么：把原始电信号读数换算成物理量，支持三种常用传感器：

1. **NTC 热敏电阻 → 温度**
   - 输入：电阻值（Ω）或直接粘贴一列电阻数据
   - 用 **Steinhart-Hart 方程**：1/T = A + B·ln(R) + C·(ln R)³；同时支持简化 **B 值式**：1/T = 1/T₀ + (1/B)·ln(R/R₀)
   - 参数可填：B（常见 3950/3435）、R₀（常见 10kΩ）、T₀（25°C = 298.15K）
   - 输出：温度（°C），保留 2 位小数
2. **ADC 原始读数 → 电压**
   - 输入：ADC 值 + 参考电压 Vref + 分辨率位数（如 12 位 4095）
   - 电压 = ADC / (2^bits − 1) × Vref
   - 可选分压系数（如电阻分压比）还原真实电压
3. **MQ 系列气体传感器 → 浓度比**
   - 输入：Sensor Resistance（Rs），配合 R₀（洁净空气标定）
   - 输出 Rs/R₀ 比值，并按常用 MQ-2/MQ-135 的 log-log 拟合段给出 ppm 近似值（写明是近似，取典型拟合系数）

交互：
- 支持手动输入单值换算（即时显示结果）
- 支持**批量模式**：选择已导入数据的某一列作为输入，换算后**生成新列**追加到数据集（后续统计/图表/报告能用这列新数据）
- 每种换算在页面上注明所用公式和参数（可追溯）

## 功能 B：采样质量分析（并入「数据预览」页签底部，新卡片）

做什么：对带时间戳的数据自动做采样质量体检，输出一张「采样质量报告」卡片：

- **实际平均采样率**：总时长/间隔数（如 9.98 Hz）
- **间隔抖动**：相邻间隔的标准差与最大偏差（如 "标称 100ms，实际 100.3ms ± 2.1ms，最大偏 8ms"）
- **丢帧检测**：相邻间隔 > 中位间隔 × 3 判为疑似丢帧，列出丢帧发生的时间点和个数
- **异常时间戳**：时间倒流/重复时间戳检测
- 无时间戳的数据：显示「无时间戳列，跳过采样质量分析」（友好降级，不报错）

## 功能 C：滤波对比实验台（新页签「滤波实验」）

放在「智能分析」之后。做什么：对选定通道做滤波处理并**前后对比**：

1. 三种滤波器可选（可多选叠加对比）：
   - **滑动平均**：窗口 N 可调（3~51，滑块）
   - **中值滤波**：窗口 N 可调（奇数）
   - **一阶低通（指数平滑）**：α 系数可调（0~1 滑块）
2. 图表：原始曲线（浅色细线）+ 各滤波结果（不同颜色实线）叠加显示，图例可开关
3. 统计对比卡片：处理前后的 标准差/极差/异常点数 变化（如 "毛刺从 2 个降到 0 个，标准差 0.54 → 0.21"）
4. 「应用滤波结果」按钮：把某条滤波结果**替换/追加为新列**（追加为默认，保留原始数据），后续分析和报告可用
5. 滤波器实现写清公式（滑动窗口均值、中值排序取中、yₙ = α·xₙ + (1−α)·yₙ₋₁）

## 功能 D：FFT 频域分析（并入「滤波实验」页签，或独立子区块）

做什么：对选定通道做频谱分析：

1. 实现离散傅里叶变换（数据量 ≤ 4096 点直接 DFT 或基-2 FFT，自己实现或引 CDN 均可，注明出处）
2. 输出**幅度谱图**（柱状或折线），横轴频率（Hz）、纵轴幅度
3. **自动标注主频**：能量最高的 1~3 个峰，在图上标出并在文字里说明（如 "主频 0.5 Hz，次频 2.1 Hz"）
4. 常见干扰提示：若谱峰出现在 50 Hz 附近，提示"疑似工频干扰"
5. 采样率未知时提示"采样质量分析未通过/无时间戳，频率轴按采样间隔=1s 估算"（不阻塞）
6. 直流分量（0Hz）默认显示但注明

## 功能 E：报告导出 PDF（并入「生成报告」页签）

- 「导出 PDF」按钮：用浏览器打印（window.print + @media print 样式表）
- 打印样式：白底、去导航去按钮、标题层级清晰、表格边框保留、图表区域留位（提示"截图插入图表"或直接把 canvas 转图片嵌入打印视图）
- 优先做：点按钮 → 打开打印对话框 → 用户另存为 PDF。不引重型库

## 功能 F：数据回放动画（并入「智能分析」页签图表区）

- 「▶ 回放」按钮：曲线从左到右按时间顺序逐步绘制（类 Chart.js 逐点 append，间隔可调 0.05x~2x 速度）
- 回放时显示当前时间点和当前值
- 回放结束停在完整图；随时可暂停/重置
- 尊重系统「减弱动态效果」（prefers-reduced-motion 时默认不高亮动画，仍可手动点播）
