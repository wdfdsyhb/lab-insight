R-T 标定图：实测点 vs 理论曲线

            

              
              
              
            

            

              
            

            
散点用实测温度列（通常是批量换算生成的温度列），理论曲线用当前 B / R₀ / T₀ 参数画 R-T 特性；两条线贴合程度即换算参数与实测的偏差。

          


          

            
两点标定反算 B 值：填两组「标准温度 → 实测电阻」自动求 B / R₀

            

              
              
              
              
            

            

              
              
              公式：B = ln(R₁/R₂) / (1/T₁ − 1/T₂)，T 取开氏温度；解出 B 后以 T₁ 为标称点回填 R₀。两点法假设 B 在区间内恒定。

多项式系数来自你自己的标定数据（可用下方线性拟合求出一次项系数），公式会写进换算记录。

线性拟合 y = k·x + b

            最小二乘法，传感器标定求灵敏度常用
          

          
选好两列后点「开始拟合」，公式与 R² 会显示在这里

          

            
            
            
          

          
X 通常取输入激励（如电压、设定温度），Y 取传感器输出读数；两列按行取共同有效值。拟合结果同时写入下方「换算记录」。

          


          
标定评估：灵敏度 · 零点 · 线性度 · 迟滞

          

            
          

          
用上方同一组 X / Y 列：灵敏度 = 拟合斜率 k，零点输出 = 截距 b，线性度 = 最大残差 / 输出量程，迟滞 = 前后半程各自拟合的斜率差异（按行序前半 / 后半，简版判定）。

          


          
自动模型辨识：7 种候选模型竞选最优

          

            
            
          

          
对上方同一组 X / Y 列自动尝试 线性 / 二次 / 三次 / 指数 / 对数 / 幂函数 / 倒数 七种模型，按修正 R²（惩罚参数数）排序推荐，预测值反变换回原始空间再评分，避免变换域 R² 虚高。

滤波实验

          
对选定通道做滤波处理并前后对比。原始曲线为浅色细线，滤波结果叠加显示，可勾选多种滤波器同时比较。

        


        
        

          

            
通道与滤波器

            勾选启用，拖动滑块调参，图表与统计即时刷新
          


          

          

            

              

                
                窗口 7
              

              
              
yₙ = mean(xₙ₋w/₂ … xₙ+w/₂)（居中窗口，边界自动缩窗）

            


            

              

                
                窗口 5
              

              
              
yₙ = median(xₙ₋w/₂ … xₙ+w/₂)（窗口内排序取中值，窗口取奇数）

            


            

              

                
                α = 0.30
              

              
              
yₙ = α·xₙ + (1−α)·yₙ₋₁，y₀ = x₀（α 越大越跟手，越小越平滑）
